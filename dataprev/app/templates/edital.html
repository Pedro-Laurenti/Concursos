Desenvolvimento de Sistemas

Linguagens, Frameworks e Plataformas

Java (≥6), JavaEE (≥6), JakartaEE, JPA (≥2), JavaScript; JUnit, Hibernate, JSF, Primefaces, Spring, SpringCloud, SpringBoot; mobile (Android, iOS); low-code / no-code

Arquitetura de Software

  • Interoperabilidade; SOA; web services; mensageria; API; Swagger; OO
  • Arquitetura web; servidores de aplicação e web
  • Microsserviços (orquestração, API gateway); containers
  • Arquitetura hexagonal; transações distribuídas
  • Blockchain; design de software

Padrões de Dados e Protocolos
